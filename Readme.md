# The MAZEEEEE Game

## Description
The MAZEEEEE Game is a simple maze racing game made using Python and Pygame.

The player (Red Square) starts at the bottom of the maze and must reach the exit at the top before the AI (Blue Square) reaches the finish.

The AI follows a predefined path while the player controls the movement using the keyboard.

---

## Features

- Main Menu
- Fixed Maze
- Player Movement
- Wall Collision Detection
- AI Opponent
- Win/Lose Detection
- Restart Option

---

## Controls

- ↑ Move Up
- ↓ Move Down
- ← Move Left
- → Move Right
- Enter - Start Game
- Esc - Exit Game
- R - Restart (when available)

---

## Requirements

- Python 3.x
- pygame-ce

Install pygame using:

```bash
pip install pygame-ce
```

---

## How to Run

Run the following command:

```bash
python game.py
```
